# Editorial imagery

The current storefront uses real representative catalog photographs in `products/`. See `products/README.md`, `scripts/data/photo-sources.json`, and the public Photo credits page for sources. The older editorial assets below are retained for existing references.

These images illustrate categories and design ideas; they are never substituted for actual seller product images, prices, or inventory.

- `everyday-headphones.webp`: generated using the built-in imagegen tool. Prompt: premium monochrome studio photograph of unbranded brushed-silver aluminum and black-leather over-ear headphones, three-quarter view on a seamless light-gray background, no text, logos, glow, or decorative objects. Generated PNG converted to WebP for delivery.
- `space.jpg`: https://images.unsplash.com/photo-1567538096630-e0c55bd6374c, served locally.
- `essentials.jpg`: https://images.unsplash.com/photo-1523275335684-37898b6baf30, served locally.
